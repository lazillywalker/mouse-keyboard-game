# 30秒ネズミ叩き・両手キーボード練習ゲーム Ver.1.2

**[▶ ブラウザで遊ぶ](https://lazillywalker.github.io/mouse-keyboard-game/)**

Threadsでの「キーボード練習で何か良いものない？」という話から作った、左右の手で違う操作をする30秒のゲームです。パソコンのキーボードで遊んでください。

## 操作

| キー | 操作 |
| --- | --- |
| W / A / S / D | 照準を上 / 左 / 下 / 右へ1マス移動 |
| J / K / L | 青 / 赤 / 黄の道具を選択 |
| I | 攻撃 |
| Space | 開始 |
| Enter | 終了後に再挑戦 |

## ルール

- 3×3の穴にネズミが1匹出現。照準は中央から始まり、端では止まります。
- 場所と道具が両方一致すれば10点。連続命中で2点ずつ増えるコンボボーナス（最大＋10点）。失敗は0点、減点なし。
- チャレンジでは、当たるか出現時間が過ぎると、次の1匹が出現します。
- チャレンジは30秒固定。練習モードは時間制限なしで、正解するまでネズミが待ちます。「練習を終了して結果を見る」ボタンで終了できます。
- 初級：5秒 / 中級：3秒 / 上級：1.5秒。開始前に選択できます。
- キーは1回ずつ押してください。長押しの連続入力はありません。

## Ver.1.2の機能

- ネズミに対応キーの **J / K / L** を表示（色は維持）。
- 選択中の道具を枠・背景・文字で強調。命中した穴は約0.22秒光ります。
- 30秒終了時刻とネズミの出現期限を攻撃判定前に確認し、期限後の加点を防止。
- 円形の残り時間ゲージ、コンボ、難易度別の自己ベスト（チャレンジのみ）を搭載。
- タブが非表示の間はゲームを一時停止。中断時間は反応時間からも除外。
- 結果に移動・道具選択の回数、場所や道具のミス、逃げた数、J/K/L別の命中までの平均時間を表示。
- 操作ログは今回のプレイ分をメモリに記録し、最新100件を画面で確認できます。再スタートで消えます。
- 命中率は命中 ÷（命中＋場所・道具のミス）。逃げた数と出現期限後の攻撃は分母に含めません。

## オフラインで遊ぶ

`index.html` をダウンロードしてブラウザで開くだけです。HTML・CSS・JavaScript・SVGはすべて1ファイルに内蔵しており、インストールやインターネット接続は不要です。音は出ません。

## 動作確認

Linux上のChromeで、WASD移動と端での停止、J/K/L選択とI攻撃、コンボ、長押し無効化、全難易度の出現期限、30秒ちょうどの入力による加点防止、実時間30秒での自動終了、一時停止と再開、自己ベスト、練習の終了・再スタート、操作ログと集計の一致を確認しました。画面幅375 / 720 / 1040pxで横方向のはみ出しがないことも確認済みです。Windows実機での確認は未実施です。
